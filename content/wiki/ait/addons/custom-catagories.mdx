## Create a Datapack

- _Follow the tutorial on the_ [_Minecraft Wiki on datapacks_](https://minecraft.wiki/w/Data_pack) _on how to set one up, use the namespace from earlier._

Create a new **.json** file in the path

`data/namespace/categories/category_name.json`

This will contain the “code” for the categorie.

Inside this new .json file, paste


```plain
{
   "id": "namespace:category_name",
  "name": "category_name"
}
```
