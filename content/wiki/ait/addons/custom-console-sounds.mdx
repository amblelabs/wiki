## Datapack

1. Create a new `.json` file in the path below.

`data/namespace/control_sounds/console_name/console_control_name.json`

2. Inside this new `.json` file, type the following:

```plain
{
 "control": "name:of_control",
 "console": "ait:console/console_name",
 "success_sound": "sound:id",
 "alt_sound": "sound:id_alt"
}
```

- Replace the `name:of_control` with one of the many console controls we have.
- Replace `console_name` with any listed below.
- Replace `sound:id` and `sound:id_alt` with the sounds id that matches what it is in-game (using the `/playsound` command)

If you don't know how to add a custom sound to Minecraft, follow [THIS VIDEO](https://www.youtube.com/watch?v=igZQdEoxcQk) !

example:

```plain
{
  "control": "ait:alarms",
  "console": "ait:console/copper",
  "success_sound": "ait:controls/copper_alarm",
  "alt_sound": "ait:controls/copper_alarm_alt"
} 
```
