## Datapack

1. Create a new `.json` file in the path below.

`data/namespace/fx/flight/flight_sound_name.json`

2. Inside this new `.json` file, type the following:

```plain
{
 "id": "namespace:name",
 "sound": "sound:id",
 "length": value
}
```

3. When replacing the `namespace:name` and the `sound:id`. Make sure that the `name` part is named the same as the json file and the sounds id matches what it is in-game (using the `/playsound` command). The length `value` field refers to the length of the sound in **seconds,** so make sure it is correct or the sound will cut off or drag on!

If you don't know how to add a custom sound to Minecraft, follow [THIS VIDEO](https://www.youtube.com/watch?v=igZQdEoxcQk) !

example:

```plain
{
  "id": "ait:eight",
  "sound": "ait:tardis/eighth_flight",
  "length": 100
}
```
