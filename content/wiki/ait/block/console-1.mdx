---
title: Console
description: The main control unit of the TARDIS
section: block
---

You can place a console in a TARDIS by placing down a coral growth on soul sand, or a console generator, which is crafted like so:

![](/images/console-generator-recipe.png)

The console can be interacted with by a player or other entities such as arrows. The TARDIS should always be piloted by 6 fully trained TARDIS pilots as to allow for a smooth journey. You might notice that it emits a nice ambience, don’t let that distract you though. Out-of-universe, the console is a collection of **Control Entities** which are located around the console block that run different functions.

It will emit a redstone signal like a redstone block when in the TARDIS, it will not emit light.
