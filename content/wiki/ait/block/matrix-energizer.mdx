The Matrix Energizer is crafted like so:

![](/images/matrix-energizer-recipe.png)

It can only be used on a naturally occuring sculk shrieker found in the Deep dark or ancient cities.

When placed on one, it will attach to the shrieker. Then, you'll need to `right-click` the energizer with a nether star and create noise to activage the shrieker.

It should have a bar similar to the [artron collector](../block/artron-collector) on its side slowly filling up if it succeeded.

When it's done, it will break and drop a matrix with a randomly generated name and hex code
