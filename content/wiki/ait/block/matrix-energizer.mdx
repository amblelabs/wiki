The Matrix Energizer is crafted like so:

![](/images/matrix-energizer-recipe.png)

It can only be used on a naturally occuring sculk shrieker found in the Deep dark or ancient cities.

**DO NOT MOVE THE SHRIEKER, DOING SO WILL DISABLE THE ABILITY TO CHARGE THE MATRIX AT ALL!**

When placed on top of a shrieker, the matrix energizer will attach. Then, you'll need to `right-click` the energizer with a Nether star and create noise to activate the shrieker.

**A naturally generated sculk shrieker will summon a Warden on the fourth activation** so be aware of your surroundings!

If the process succeeded, it should start filling up a bar on the side of the Matrix Energizer block.

When it's done, it will break and drop a matrix with a randomly generated name and hex code.
