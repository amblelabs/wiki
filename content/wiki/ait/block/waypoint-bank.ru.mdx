Хранилище Путевых Картриджей - это хороший способ облегчить хранение Путевых Картриджей.
Просто вставьте их и активируйте их, не подходя к консоли, из любого места в своей **ТАРДИС**!

У Хранилища Путевых Картриджей всего 16 слотов, в которые вы можете вставить Путевой Картридж, нажав `ПКМ` по пустому слоту, держа (не пустой) Путевой Картридж в своей руке.

Вот все способы взаимодействия с Хранилищем Путевых Картриджей:

- Возьмите свой Путевой Картридж и нажмите `ПКМ` по пустому слоту, чтобы вставить его.
- Нажмите `ПКМ` по слоту со вставленным Картриджем, чтобы наполовину достать его. Это покажет информацию о Картридже на экране.
- Ещё раз нажмите `ПКМ` по тому-же слоту, чтобы поставить выбранный Путевой Картридж в качестве пути.
- Зажмите `SHIFT` и нажмите `ПКМ` по слоту с наполовину вытащенным Картриджем, чтобы полностью достать его.
- Нажмите `ПКМ` по другому слоту, чтобы наполовину достать другой Картридж. (Прошлый Картридж будет выставлен обратно.)
- Нажмите `ЛКМ` по нижней части Хранилища, чтобы вставить все наполовину вытащенные Картриджи обратно.
