## Client Config

**Interior hum volume** Can be set to a value between 0.0% and 100.0% Allows you to change how loud or quiet the interior hum is.

**Use custom main menu** Turns on or off ait’s custom title screen

**Show experimental warnings** This config makes it so you can see the warnings if you are on a ait beta. **(Currently Broken)**

**Render local sky box** This config toggles the environment projector rendering (**Currently Broken)**

**Enable TARDIS boti** This config allows you to toggle bigger on the inside on your TARDIS so you can see the vortex and the end portal texture thing.

**Render boti interior** (**Currently Useless)**

**Green screen boti** turns your TARDIS's portal texture green, don't use this unless you do video editing.

**Show control hitboxs** This config allows the [**sonic**](../item/sonic-screwdriver/) when in scanning mode to show console control hitboxes.

**Show text on console monitors** This config toggles the flight information on the console monitors. (toyota console, coral console, etc...)

**Show text on crt monitors** This config toggles the flight information on the crt monitors (the one about the size of a head)

**Render demat particles** This config toggles the smoke on the exterior when dematerializing.

**Animate console** This config toggles the animations on the console. (power, demat, the little tiny lights on most consoles etc)

**Animate doors** This config toggles the animations of doors so instead of it having really nice moving doors, you'll get terrible doors (i don't see why you would turn this off though, unless your pc is less than a potato)

## Server configs

**Minify json** Allows you to minify the TARDIS json and removes line breaks and spaces from the 

**Ghost monument** Toggles the random teleporting of the TARDIS exterior when the engine is phasing

**Lock dimensions** Enables the locking of dimensions for the TARDIS

**Enable rwf** (Broken Do NOT USE) allows you enable the real world flight of the TARDIS

**Can tnt teleport through doors** Enables whether primed tnt can enter the TARDIS doors

**Enable hypercubes** Enables whether or not hypercubes are usable

**Travel per tick** Default Value: 2 Changes the rate of Travel per tick

**Send Bulk** Toggles between sending TARDISes as bulk packets and separate packets

**Max amount of tardises** Defaults to -1 which is no limit Changes how many TARDISes a save can have

**Disable safeguards** Disables safeguards (Pretty self explanatory)

**Environment projector black list** blacklists dimensions from the environment projector skybox list

**TARDIS travel world black list** Blacklists dimensions for the TARDIS to travel to

**rift spawn world black list** Blacklists what dimensions rifts cannot spawn in

**rift drop world black list** Blacklists what dimensions rifts cannot drop items in
