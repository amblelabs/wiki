# Engine Phasing

## What IS Engine Phasing? 

Engine phasing is a negative consequence of your dematerialization circuit and engine having low durability, once the circuit reaches 300 durability (or less), engine phasing may randomly occur. If it does, the following things happen;

- TARDIS position randomized
- Causes the TARDIS to “Ghost Monument” 

## How do I counter this? 

- Keep circuit durability high
- Use [**sonic**](../item/sonic-screwdriver) with the [**TARDIS** **mode**](../item/sonic-screwdriver/#tardis-mode) on the exterior to cancel engine phasing

## Ghost Monument 

Ghost monuments needs the following to be done to be triggered:

- Have `Leave behind` set to `false` in the security settings (is false by default).
- Have `Ghost Monument` enabled in the server config (is enabled by default).

If you then go to the destination spot you’ll see the TARDIS land and stop because it ran out of power.
